# Montfortre

NYC real-estate site (React / Vite / TypeScript).

## Setup

```bash
npm install
npm run dev
```

## Git

- **Remote:** `origin` → `https://github.com/FerozArshad/montfortre.git` (`main`)
- App lives at the **repo root** (not a nested folder).
- Optional live deploy clone: `_lovable_push/` → Lovable `smontfort/monttfortre` (local only, gitignored).
