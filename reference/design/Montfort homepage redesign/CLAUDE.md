# Montfort Real Estate — Brand Kit

Apply this to every page in this project. Follow strictly.

## Typefaces
- **Space Grotesk** — all headings and display text. Bold, geometric sans. Default weight **700**, negative tracking.
- **DM Sans** — body copy, navigation, buttons, all UI text. Weights 400 / 500 / 700.
- **Generic serif** (Georgia / Cambria / Times) — decorative ONLY, for the large gold quotation marks in testimonials. Never for real headings or body.
- Do NOT use Inter, Roboto Mono, Prata, or Archivo — they are not part of this kit.

Google Fonts:
`https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700&family=DM+Sans:opsz,wght@9..40,400;9..40,500;9..40,700&display=swap`

## Type scale

### Space Grotesk — headings / display
- 72px / 700 / -1.8px — Hero H1
- 36px / 700 / -0.9px (sentence case) · 36px / 700 / -1.8px (uppercase) — H2
- 30px / 700 / -0.75px — large stat / subheading
- 24px / 700 / +1.2px, uppercase — H3 (section titles)
- 20px / 700 / -0.5px, uppercase — small heading
- 18px / 700 / +0.9px, uppercase — H4

### DM Sans — body & UI
- 30px / 700 / -1.5px — large numeric stats ("$1B+")
- 20px / 400 body · 20px / 700 bold inline emphasis
- 18px / 400 · 18px / 500
- 16px / 400 default body & nav · 16px / 700
- 14px / 400 · 14px / 500 buttons · 14px / 700 · 14px / 700 +1.4px uppercase (small CTA labels)
- 12px / 400 · 12px / 700, usually uppercase +1.2px (labels / badges)
- 10px / 400 — micro / fine print

## Colors

- Gold `#C98A2C` (accent) · Soft gold `#F0D9A8`
- Cream `#F9F6E6` (page bg) · Warm cream `#F5EECB` · Cream border `#E0D9B8`
- Slate body text `#3B4C5E`

## Global UI standards
- Border radius: cards/panels **16px**, menu items/list rows **10px**, pills/CTAs **100px** (rounded) or **10px** (rectangular).
- Icons drawn as SVG (rounded caps/joins), never basic glyph arrows.
